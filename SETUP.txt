NEXUS Playback Bar for Windows - Preview 29

1. Extract the complete ZIP into a folder you can keep, such as Documents.
2. Quit any running copy of NEXUS Playback Bar from its tray menu.
3. Run Install-NEXUS.cmd, then open NEXUS Playback Bar from Start.
   Install Python 3 with Tkinter and py.exe first if needed. The installer
   generates a local key for the Windows app and the extracted Chrome folder.
4. For Chrome, open chrome://extensions, enable Developer mode, and select
   Load unpacked. Choose this ZIP's extracted chrome folder. Disable any
   older copy and refresh open media tabs. Reload the extension if it is
   already using this exact folder. Keep the folder in place.
5. Connect the Corsair iCUE NEXUS by USB. If iCUE is using the screen,
   fully quit it or follow the module workaround in the GitHub README.

Tap or drag the timeline to seek. Choose whether to send live seeks during
a drag. Windows desktop apps require a supported seekable media session.

Open Idle to configure up to eight widgets per page. Swipe sideways on
the NEXUS to switch dashboard pages. To switch between playback and idle,
place two fingers at least one inch apart near the top and swipe down,
away from the playback marker. Use Follow playback to restore automatic
switching. See the GitHub README for example screenshots and the full guide.
